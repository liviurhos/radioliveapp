About RadioLive

Your free, open-access radio player for the web — and available as a native app on Android & iOS.

All Genres

Pop, Rock, Jazz, Classical, News, Talk — curated stations for every mood.

Native Apps

// The Project

RadioLive was built by Innovation Hub Studio Ltd, a UK-based mobile app studio. The mission is simple: make radio accessible to everyone, everywhere, for free.

The station database is community-driven and continuously updated, covering national broadcasters, indie stations, and genre-specific channels across Europe, the Americas, and beyond.

// Technology

  • Android app built with Kotlin & ExoPlayer
  • iOS app built with Swift, SwiftUI & AVPlayer
  • Web player powered by the HTML5 Audio API
  • Station database hosted on GitHub as open JSON
  • Continuous expansion via pull requests and community feedback

Frequently Asked Questions

Everything you need to know about RadioLive — web, Android, and iOS.

// General

RadioLive is a free radio streaming app that lets you listen to hundreds of live radio stations from Romania, Germany, UK, USA, and 20+ other countries. It's available as a native app on Android and iOS, and as a web player at radioliveapp.co.uk. No account, no subscription required to start listening.

Yes. The web player is completely free with no ads. The mobile app is free with optional ads. We also offer a Premium tier (£0.49/month or £4.99 lifetime) on mobile that removes all ads. The core streaming experience — all stations, all countries — is always free.

No account is required. Open the app or website and press play. Your preferences (theme, volume, favourites) are stored locally on your device only.

Currently 350+ stations across 25 countries including Romania, Germany, UK, USA, France, Italy, Spain, Greece, Turkey, and more. We continuously add new stations — suggest one via the Contact page!

// Web Player

Some radio stations broadcast on unencrypted HTTP streams. Modern browsers block these when the page is served over HTTPS — this is a browser security policy, not a RadioLive limitation. These stations are marked with a 📱 App only badge. They play perfectly in the Android and iOS apps, which don't have this restriction.

Other stations may also block direct browser access (CORS policy). Again, the mobile apps bypass this entirely.

Buffering is usually caused by your internet connection or the radio station's server load. Try: refreshing the page, switching to a lower-bitrate station of the same broadcaster, or using the mobile app which uses ExoPlayer/AVPlayer for optimised adaptive buffering.

Track metadata (ICY metadata) embedded in radio streams is not accessible to web browsers due to cross-origin restrictions. The mobile apps can read this data directly. On the web player, your OS media controls will show the station name and logo via the MediaSession API, but not the individual track title.

RadioLive works on all modern browsers: Chrome, Firefox, Safari, Edge, and Opera. We recommend Chrome or Edge for the best experience. Internet Explorer is not supported.

Yes. Once a station is playing, your keyboard's media keys (play/pause) and your OS media controls (Windows taskbar, macOS Control Centre, lock screen on mobile) all work with the web player via the MediaSession API.

// Mobile App

RadioLive is available on the Google Play Store (Android) and the Apple App Store (iOS). Search for "RadioLive" or use the download links on the main page.

Yes. The mobile app runs as a foreground service (Android) or background audio session (iOS), meaning it keeps playing when you lock your screen or switch apps. Lock screen controls (play, pause, station info) are fully supported on both platforms.

Yes, fully. RadioLive integrates with the system audio stack on both Android and iOS, so it works with any Bluetooth device, wired headphones, car audio via Android Auto, and AirPlay on iOS.

Tap the heart/star icon on any station to add it to your favourites. Access your favourites list from the Favourites tab in the app. Favourites are stored locally on your device.

Occasionally a radio station goes offline, changes their stream URL, or experiences technical issues on their end. This is outside our control. Try: waiting a few minutes and retrying, checking if the station's own website is working, or reporting it to us via the Contact page so we can update the database.

Data usage depends on the station's bitrate. As a guide: a 64 kbps stream uses ~28 MB/hour; a 128 kbps stream uses ~56 MB/hour; a 320 kbps stream uses ~144 MB/hour. Most stations stream between 64–192 kbps.

No — RadioLive streams live radio in real time and requires an internet connection (WiFi or mobile data). There is no offline/download feature, as radio content is live by nature.
